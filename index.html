⏰ 毎日・隔日・週1のお薬＆サプリを一元管理

お薬の飲み忘れを防ぎ、
サプリの「飲み時」も迷わない。

処方薬・市販薬はお薬袋の指示どおりに毎日・隔日・週1回まで柔軟にスケジュール管理。サプリメントは市販成分カテゴリに応じた参考タイミング表示や成分重複チェックも無料で使えます。

※ 実際の服薬データのクラウド保存・マルチデバイス同期には無料会員登録（メール認証）が必要です。「ゲストでお試し」ではサンプルデータ入りで操作感を体験でき、登録時にデータ引き継ぎも可能です。

📱 ノミドキでできること
  • ✓ ワンタップで「飲んだ！」記録：押すだけで服用時刻と残薬数を自動カウント。記録忘れのさかのぼり追加や取り消しも対応。
  • ✓ 隔日・週1・曜日指定スケジュール：毎日だけでなく1日おき・週1回の予定もカレンダーに自動反映。
  • ✓ サプリ名称入力で飲み時ガイド：サプリメント名を入力すると該当成分を絞り込み、吸収特性に合わせた参考タイミングを提案。
  • ✓ 深夜4:00（28:00）日付切替：深夜0時を過ぎた就寝前のお薬やトレーニング後のプロテインも当日分としてそのまま記録可能。
FEATURES

毎日の服薬・サプリ管理を無理なく続ける工夫

処方薬の安全性への配慮と、日々のセルフケアの使いやすさを両立しています。

残薬カウント＆月別服薬カレンダー

「飲んだ！」ボタンを押すだけで残薬数が自動カウントされ、残り少なくなると補充アラートでお知らせ。月間カレンダーから飲んだ時刻と内容も振り返れます。

処方薬・市販薬の安全設計

処方薬・市販薬には定められた服薬タイミングが存在するため、アプリからの自動提案は行わず、お薬袋・添付文書の指示どおりに正確に記録できる設計です。

サプリメントの参考タイミング＆重複チェック

サプリメント登録時は、脂溶性ビタミン・水溶性ビタミン・鉄分・乳酸菌などの特性に応じた参考タイミング表示や、複数サプリ間の成分重複アラートが役立ちます。

プライバシーポリシー（個人情報保護方針・外部送信規律に関する公表事項）

ノミドキ運営事務局（以下「当運営」といいます）は、Webアプリケーション「ノミドキ（Nomidoki）」（以下「本サービス」）における利用者の個人情報の取扱いについて、以下のとおりプライバシーポリシーを定めます。

1. 取得する情報と利用目的

  • アカウント情報：メールアドレス、パスワード（暗号化処理）、表示用ニックネーム（本人確認、ログイン認証、パスワード再設定、およびお問い合わせ対応のため）。
  • 服薬・サプリメント管理データ：利用者が任意で登録したお薬・サプリメントの名称、服用タイミング、残薬数、服用履歴（クラウド同期によるマルチデバイス利用および自己管理機能の提供のため）。
  • ゲストモードの一時データ：お試し体験用のサンプルおよび一時入力データは利用者のブラウザ内（localStorage）にのみ保存され、外部サーバーへは送信されません。

2. データの保管先および安全管理措置

本サービスの会員認証およびクラウドデータ保管には、Google LLC が提供する「Firebase Authentication」および「Cloud Firestore」を利用しています。通信はすべて SSL/TLS により暗号化され、認証された利用者本人のみが自身のデータへアクセスできるようセキュリティルールを設定しています。

3. 広告配信および外部送信に関する事項

本サービスでは、運営維持のために第三者配信の広告サービス（Google AdSense 等）を利用する場合があります。広告配信事業者は、利用者の興味に応じた広告を表示するために Cookie 等を使用することがあります。Cookie を無効にする設定および Google による広告配信の詳細については、Google ポリシーと規約をご確認ください。

4. 個人情報の開示・訂正・削除（退会）

利用者は、ログイン後の「設定・規約」画面から登録情報の修正およびアカウント・クラウドデータの完全削除をいつでもご自身で実行できます。
